# 🛒 Projeto E-commerce (Em Desenvolvimento)

Este é um projeto de e-commerce desenvolvido com **React**, com o objetivo de praticar conceitos modernos de desenvolvimento front-end, como componentização, gerenciamento de estado e criação de interfaces responsivas.

## 🚧 Status do Projeto

O projeto ainda está em desenvolvimento e novas funcionalidades estão sendo implementadas continuamente.

## 💻 Tecnologias utilizadas

- React
- Vite
- Tailwind CSS
- JavaScript

## ⚙️ Funcionalidades atuais

- Estrutura inicial do e-commerce
- Validação de formulários
- Navegação entre páginas
- Layout responsivo (mobile-first)
- Abertura e fechamento do carrinho

## 🔜 Próximas melhorias

- Integração completa do carrinho de compras
- Listagem de produtos
- Persistência de dados
- Melhorias na experiência do usuário (UX/UI)

## 🎯 Objetivo

Este projeto tem como foco o aprendizado prático no desenvolvimento de aplicações front-end, simulando um ambiente real de e-commerce.
